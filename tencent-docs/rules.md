# 騰訊文件平台規範草案

## 範圍與既有材料
整理 w0x7ce-post-to-tencent-docs 的文字文件建立與填入流程。現有 CLI 接受 title、content、submit、profile；不把舊指南中的 markdown、file、type 參數或試算表、投影片能力當成已實作。

## 內容與交付
標題、正文、段落與來源清楚，依文件用途決定排版。不強制套用微信正文按鈕或社交貼文格式。需要 Markdown 時由 Agent 先準備內容，不把未實作的 CLI 參數當成轉換器。

## 操作與驗收
此腳本即使未傳 submit，也可能建立並寫入自動保存的雲端文件，因此預覽不是無外部寫入。先取得對文件建立與寫入的授權；submit 主要控制瀏覽器保留行為，不等於對外分享或設定權限。

## 待確認
這份完整規範待人確認。回報實際可見文件網址及保存狀態，未測試時不聲稱分享、權限設定或不同文件類型可用。
