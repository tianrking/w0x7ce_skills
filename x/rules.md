# X 平台規範草案

## 範圍與既有材料
整理文字、圖片、影片貼文及 Markdown 長文的既有流程。現有 Skill 為 w0x7ce-post-to-x；不因目錄遷移宣稱所有帳號、介面與影片規格都已測試。

## 內容與交付
延用共用品質要求，依短貼文或長文選擇結構。保留完整正文、圖片及引用來源；不將微信的 HTML 按鈕要求套用到短貼文。標題、封面和長文能力依當次需求與帳號實際功能確認。

## 操作與驗收
先準備可審閱內容，預覽與公開發布分開。明確獲准發布後才使用提交動作。輸入成功不等於公開發布成功；回報可見的保存或發布結果及未驗證部分。

## 待確認
這份規範由舊 Skill 梳理而來，完整版本尚待人確認。平台字數、媒體額度及長文資格不寫成永久常數。確認後再驗證與記錄既有 Skill 的新規範版本。
