# X 內容編輯與發布規範草案

本文件待確認，共同品質引用根目錄 shared-rules.md。

## 內容與結構

適用於單則貼文、串文、圖片或影片配文，以及帳號實際支援的長文。按題材選形式，不預設所有主題都做串文。

使用自然、清楚的繁體中文，其他語言依需求。語氣中肯、謙遜、專業，不強制情緒化開頭、Emoji、Hashtag、懸念或互動誘導。

單則有清楚中心；串文按理解順序拆分，標明順序與各則媒體；長文交付完整正文。只在需要標題的形式單獨提供題目。必要背景、條件及來源不能為簡短而失真。

跨平台改編保留原意、證據及限制，再調整節奏與篇幅，不直接截斷原文。數字、引文及重要結論可追溯；來源、推論、示意與實測分開，時效資訊核對日期或版本。

## 素材與交付

配圖有資訊作用，媒體順序與正文一致，不固定張數；標註清楚，重要元素留出裁切空間。需要封面時生成或尋找合適且可使用的圖片，交付原檔；純文字貼文不強制封面。生成圖不冒充官方畫面、照片或驗證證據，外部素材保留來源與必要使用條件。

提供可直接複製的最終全文，串文逐則分開並對應媒體，操作說明不混入正文。長文適配實際編輯器，不強制微信 HTML 與兩個按鈕。

需要保存、跨平台改編或含素材的作品，交付完整 Markdown、相對路徑 images/ 或 media/、來源與簡短說明，另提供保留目錄結構的 ZIP。一次性純文字短貼文可直接交全文，不建立空素材資料夾。多格式與發布版本保持一致。

## 操作與驗收

核對實際帳號、內容形式及當次字數、媒體和長文資格，不把變動額度寫成永久常數。

準備、預覽、保存草稿與公開發布分開回報；當次指示已授權發布才提交。輸入或點擊成功不等於發布成功，核對可見內容、順序、媒體及結果網址。需要證明草稿持久化時，保存後重新開啟檢查。

未驗證能力如實說明，本機檢查不代替平台結果。憑證、Cookie 與私人資料不進入規範、素材包或 Git。
